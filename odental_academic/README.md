# O Dental Académico

Módulo institucional para universidades y centros docentes que atienden pacientes mediante
estudiantes bajo supervisión clínica.

## Controles principales

- Perfil estudiantil aislado del acceso clínico general.
- Programas, períodos y rotaciones con fechas controladas.
- Casos visibles únicamente para el estudiante asignado durante la vigencia autorizada.
- Ficha académica con información mínima; el expediente completo permanece institucional.
- Trabajos clínicos enviados, aprobados o devueltos por el docente.
- Correcciones versionadas sin sobrescribir el envío original.
- Evoluciones y odontogramas se incorporan únicamente como borradores supervisados.
- Vencimiento automático y revocación inmediata de accesos.
- Calificación, nivel de competencia y reportes de procedimientos por estudiante.
- Auditoría inmutable de asignación, revisión, aprobación e incorporación.

El estudiante nunca se convierte en propietario del expediente ni puede firmar directamente una
evolución clínica institucional.
