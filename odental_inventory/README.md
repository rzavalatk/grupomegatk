# O Dental Inventario Clínico

- Define protocolos de materiales por servicio.
- Genera automáticamente un consumo pendiente al finalizar una cita.
- Conserva cantidad prevista y cantidad realmente utilizada.
- Exige lote o serie en productos con trazabilidad y rechaza lotes vencidos.
- Crea una transferencia estándar de Odoo para revisión y reserva de existencias.
- Nunca valida ni descuenta inventario automáticamente: un usuario autorizado debe
  validar la transferencia en Odoo y después confirmar el resultado en O Dental.
- Mantiene separación por organización y bitácora clínica del consumo final.
