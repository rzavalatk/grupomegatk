# Espacio O Dental

Configurable por compañía desde Ajustes > Empresas > Espacio O Dental.
El selector de compañía nativo recarga la sesión y aplica su selección de aplicaciones.
Sin configuración, conserva todos los menús originales. Una lista vacía también conserva
la navegación para evitar bloquear accidentalmente al administrador.

Filtra el lanzador y la búsqueda de menús; no cambia permisos ni bloquea enlaces directos.
Solo muestra aplicaciones ya instaladas y permitidas al usuario. No instala dependencias ERP.
Desactivar el campo revierte la simplificación. Mantener Ajustes en la lista para administradores.
