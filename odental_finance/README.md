# O Dental Cuentas por Cobrar y Comisiones

Bloque financiero clínico para Odoo 18:

- cartera y saldos vencidos por paciente;
- convenios sobre facturas publicadas y pendientes;
- prima, cargo financiero, cuotas semanales, quincenales o mensuales;
- abonos aplicados desde cobros contables ya registrados;
- reglas de comisión por profesional y servicio;
- liquidaciones calculadas sobre cobros reales, con impuestos excluidos;
- aprobación y pago separados, con referencia obligatoria.

Los convenios no alteran ni concilian facturas por sí solos. Las comisiones se preparan para revisión y nunca generan pagos o asientos silenciosamente.
